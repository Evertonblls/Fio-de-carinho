Para Quem NÃO é Essa Biblioteca?

Valorizamos a transparência. Para que você faça a escolha certa, saiba que este acervo:

Não é matriz para máquina: são riscos em PDF para serem bordados livremente à mão.

Não é um produto físico: você recebe o material digital por e-mail, sem envio pelos Correios.

Não ensina a bordar: o material não inclui aulas de pontos, é a coletânea dos modelos.

O arquivo não pode ser revendido: venda à vontade as peças que você bordar, mas os arquivos digitais são de uso pessoal, para suas próprias encomendas.

Perguntas Frequentes

É produto físico?

Não. É um material 100% digital, entregue em PDF por e-mail, sem envio pelos Correios.

Como vou receber?

O acesso é liberado automaticamente no seu e-mail assim que o pagamento é confirmado.

Preciso saber desenhar?

Não. Os riscos já vêm prontos: você só transfere para o tecido e borda seguindo o traço.

Posso imprimir em casa?

Sim. Qualquer impressora doméstica em papel comum já é suficiente para imprimir os riscos.

Posso usar os riscos em peças que vou vender?

Sim. Você pode vender livremente as peças bordadas que produzir a partir dos riscos, inclusive em encomendas. O que não é permitido é revender ou compartilhar os arquivos digitais: eles são de uso pessoal.

Posso acessar pelo celular?

Sim. Você pode abrir o material e mostrar os modelos direto do celular. Para imprimir, use um computador ou uma impressora compatível com o celular.

É pagamento único?

Sim, pagamento único, sem mensalidade.

Como funciona a garantia?

Você tem 7 dias para acessar o material. Se não for para você, basta enviar um e-mail dentro do prazo e devolvemos 100% do valor.

Os arquivos servem para máquina de bordado?

Não. São riscos para bordado 100% manual — não são matrizes ou arquivos para máquina de bordar.
